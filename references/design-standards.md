# 正式学术报告视觉标准

默认以 `config/academic-theme.json` 为唯一主题源，采用根`design-system.md`已验收的Modern Scientific Editorial（暖白/白底、深绿与克制科学配色），16:9。中文 Microsoft YaHei、英文 Arial；字体替换必须实际查看 PowerPoint 渲染，不能仅凭已安装字体清单推断。百分号、图件显示尺度、简洁引用与讲稿节奏的实际检测见[质量规则](quality-standards.md)。

## 叙事驱动的页面

新论文按[研究类型与路由](research-routing.md)确定科学任务，使用同一栅格/字体/配色下的通用页类。不能继承其他论文的目录、变量和科学事实。SEM、地图及公式的科学结构不能被普通流程替代。新字号以根设计体系为准：封面56–64、标题30–34、正文20–24、次级18–20、刻度16–18、图注12–14pt；下文36pt封面仅属旧基础路径。

- 每页一个主要信息点，标题表达结果或判断；背景/方法标题应具体。长解释放讲稿，正文最多四个短陈述。
- 图表/原图通常占主内容区域约三分之二，正文是解释而非逐项复述图中标签。完整图例、统计标记和来源保持可读。
- 按内容选择已注册的Modern Scientific Editorial页类，旧基础布局仅兼容既有任务。具体真实论文验收与未核验范围见最新交付审计，不能用历史合成验收或单篇论文通过承诺任意论文质量。
- 避免重复卡片、机械三栏、虚构图标、炫光、装饰性网格、无意义流程线和过小图表。图表文字与正文不能靠缩成脚注解决密度。
- 默认封面 36pt、标题 30pt、正文 22pt、来源 14pt；修复下限分别 32/28/20/12pt。来源内容过长时重新组织引用/计划，不能无限缩小。

## baoyu 与单一输出引擎

读取 baoyu 的设计指导后，使用实际安装 deck-stage 组件承载离线 HTML 预览。预览不请求外网字体/CDN。`design` 使用同一数据规格创建 HTML 与原生 PPTX，避免两个版本的科学内容分叉。

本独立包包含真实deck-stage组件与设计指导，不包含baoyu `gen-pptx`独立导出器；`--probe-baoyu`明确报不可用。内部历史探针成功不代表随包提供该能力。正式输出始终由PptxGenJS生成，不能将HTML预览冒充可编辑PPTX。

正式 PPTX 固定 PptxGenJS，简单 chart 原生可编辑，其余论文图件用原始像素。Guizang为另行审查许可的可选对照，不随本包分发或混入生成器。

## 审查与修复

复杂原图的局部可读性改进遵循“完整原件＋原生中文读图提示”：优先扩图、删重复解说；中文提示放图外，不能覆盖原刻度、色标或显著性标记。只复述已核验的分组、单位、方向与端点，不补画未知数据。可使用`visual.largeReadingGuide:true`启用18pt提示/16pt边界说明（适用已支持的figure/distribution/figure-commentary），`readingCue`用于顶部引导；统计摘要另需定义契约。原图内细字仍以实际PNG单独审阅，不声称所有图内文字达到18pt。

相邻比较页可以保留对应构图，但要说明各自科学任务，保持图号/量纲/色标差别。不能为视觉统一改科研配色、为版式差异随机重排科学关系。页外提示不是通用地图模板；其他学科根据其原图选择解释方式。

新增密度/留白、跨页几何重复筛查；新运行核对实际PDF字体资源及PowerPoint文本边界，并逐页成对审查HTML预览与PowerPoint PNG。字体资源匹配不证明每个字形未替换。所有review提示需逐项理由，error修复重导出，不给自动美学分。详情见[质量规则](quality-standards.md)。

1. Chromium DOM 预检文字溢出并保存 PNG；最多两次安全字号修复，保留每次问题与修改日志，不改事实或数据。
2. 检查原生 OOXML 对象和实际 PowerPoint PDF/PNG；HTML 预检不等价于 PowerPoint 排版。
3. 逐页查看2560×1440 PowerPoint图像（旧基础路径1600×900）；核对中文断行、数值及百分号、误差含义、原图完整与实际可读性、简短来源、讲稿和时间。不能仅据对象边界判定合格。
4. 发现问题从 C 计划或有测试的 D 编译器修复，更新真实审阅，再构建、重新导出和复查。自动修复仅覆盖机器可确定的问题，不声称自动理解所有视觉缺陷。
5. 视觉审阅绑定实际 PNG/PPTX/QA 哈希，未查看页面保持 pending；最终交付必须无未解决阻断项。

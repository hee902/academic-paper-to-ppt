# 设计与实际渲染质量规则

这些是已在本项目真实PowerPoint导出上验证的工程筛查，仍需逐页视觉审读。继续使用同一主控和PptxGenJS，不修改科学数值来适配版式。阈值集中于`config/editorial-quality-policy.json`，不复制或改动`config/presentation-defaults.json`中的演讲默认参数。

## 数值与百分号

数值和百分号属于一个显示单元。原生百分比chart由`studio_native.cjs`在PptxGenJS生成后，只规范图表标签文本体的`wrap="none"`；不改系列、工作簿、格式数值或图形数据。PptxGenJS 4.0.1自身没有对应的数据标签换行参数，适配器因此保留明确的OOXML检查。仍保留柱尾空间，不靠缩小标签掩盖拥挤。

F同时检查实际PowerPoint的DataLabel.Text和同次导出PDF的字符坐标：数字与%/％不得跨行；图表对应标签必须在图表显示区域内找到，不能拿页面其他文字中的相同数字冒充。原图内部不可选择的百分号仍需查看PNG，自动PDF字形检查不覆盖图片像素。COM图表TextFrame2在本机可能不可用，失败会原样记录，使用真实PDF字形检查而非伪造行数。

## 原始科研图件

按原比例完整嵌入，不裁掉坐标、图例或不确定性。预检会筛出显示面积低于页面12%、短边小于2英寸的科研原图；这是review级提示，比例特殊但可读的图可以经实际审阅说明理由，不是任意论文的通用美学定律。

对计算摘要等文字密集原图，可在`visual.figureLegibility`记录绑定资产SHA的`referenceTextSizePt`、`referenceFigureWidthPt`、`measurement`和`role: calculation-summary`。D按实际显示宽度换算参考文字等效字号，当前项目目标不低于18pt。测量须来自PDF原始字体/尺寸或明确人工实测，不猜读原图数据，也不把一个参考字号当成图中所有文字字号。没有可靠测量的栅格图保持“需实际视觉审阅”，不能自动认证可读。

太小时优先扩大原件，压缩重复解说或采用有来源的局部放大，同时保留完整原图和定位；不为美化重绘未知数据。历史计算图放大案例见本项目精修审计，不继承它的图号、单位或固定宽度。

## 可见引用与完整证据

可见页脚仅用经过核验的作者年份和关键图/表/章节。`visual.sourceEvidenceIds`是该页claimIds实际引用证据的唯一子集；编译器从B证据位置派生Fig./Table/§，不接受自由编造图号章节。全量证据ID、PDF页码及定位继续写入PowerPoint备注的[Sources]与证据报告。

来源超过64字符、超过4个主要定位会阻断并要求重新选取；F另查实际来源文本是否换行。单行也不等于引用足够准确，仍需实查图号与章节。长论文题名/多来源时应组织简短标识，完整书目留备注/附录，不能无限缩字号。

## 讲稿与时间

`C/plan.json.deliveryTiming.readingAndTransitionSeconds`明确读图、翻页与停顿余量。D计入讲述与余量，检查15–20分钟生产范围及当前时段上限。中文字符/秒大于4、英文大于190词/分钟、单页超过150秒、结论不足60秒是review级节奏提示；它们是粗筛而非实测标准，可依据实际内容说明理由，不强制给所有论文相同页时长。结论多条且需讨论时合理延长，不添加重复口播凑时长。

## 跨论文终审增量

这些项目逐页实质审核，不由对象边界自动认证：

| 项目 | 必须记录的判断 | 已实现的机器检查与限制 |
|---|---|---|
| ±的含义 | 原文定义或当前源公开数据对应；作者报告和复算结论分别标明 | `statisticalDefinitions`声明后核对来源哈希、比较差值、样本均值/SD、单位及C摘要；不自动猜任意±含义 |
| 不同面板可比较性 | 图号、状态/变化、基准、色标端点及分组含义逐项核对 | 原图字节/显示比例及数字来源门禁保留；不自动理解地图或显著性括号 |
| 图外中文提示 | 原轴、色标和标记均可见，提示不遮挡、不扩大科学结论 | 原生文本同标题/Notes进入数值与布局检查；光栅细字仍需实际查看 |
| 箱线/系数 | 箱须定义、组对、ns、零线、区间类型及水平准确 | 记录原图/补充表核对；非显著不等价、模型关联不因果须实质审阅 |
| 逐页缓冲 | 复杂图留读图时间，末页留收束/讨论余量，无重复填时长 | 可选`perSlideBuffers`须完整覆盖页ID、非负整数且总和等于总余量；仍非试讲 |

更改C/编译器后重新构建导出到新目录，实际查看最终代PNG及HTML并绑定哈希；此前图片观察不能批准新代。报告保留现场投影距离、光栅细字、跨机字体及领域推断的人工核验范围。与旧案例比较时区分“两次真实生产已有证据”和“本轮新增规则的单次真实数据测试/兼容性探针”，不将回归测试数量当美学证明。

新 `generalized-editorial-v1` 还须完成下述检查；旧已完成运行不追填。F的 `editorialChecks` 在原四项之外增加 `statistical-units/density-and-rhythm/font-fidelity/html-pptx-consistency`。每页checks增加 `font-fidelity/html-pptx-consistency`，并记录对应D预览的 `htmlPreviewSha256`。两个预览及PPTX/PDF哈希任一变化，重新检查并绑定。D和F的review发现均在 `editorialDispositions` 逐项填写；error不能用接受理由绕过。截图哈希记录证明绑定，不证明真的审阅过，Codex须实际查看每张图。

| 缺陷 | 执行筛查/审阅证据 | 修复与边界 |
|---|---|---|
| 百分号拆行 | 显式换行、原生chart no-wrap、真实PDF字形行及COM标签值 | 扩标签区域/简化邻近内容；不改数值、单位或只检查字符串 |
| 统计单位/区间错误 | B角色、单位、水平、端点与C原生摘要一致；PNG核对原图/摘要/图注 | 保留真实单位与区间性质；比值可显式对数轴，不通用套零轴 |
| 图过小/坐标色标不清 | 面积/短边筛查、源绑定参考字号；逐页放大PNG并回原图 | 扩大/分讲解；未知光栅字不声称自动测准，不删除色标/误差 |
| 来源冗长 | 字符/定位数门禁及实际PowerPoint来源行 | 可见保留精确图/表/章节，全证据放Notes与审计 |
| 文字拥挤/留白失衡 | 字数阈值、内容区域栅格覆盖率review、DOM与实际COM文本边界 | 删重复解释/改布局/拆页，不无限缩字；覆盖率不是美学分 |
| 页面机械重复 | 连续三页相同内容几何，或多数页面同类layout提示 | 按科学任务调整，不能仅改layout名字或加装饰；必要对照可解释保留 |
| 中英字体替换 | 请求字体、COM返回字体、PDF BaseFont资源及配置别名；PNG检查字形 | 使用已验证本地字体或记录合法回退，再导出；资源匹配不证明每个字符 |
| HTML/PPTX不一致 | 同源规格数值/原图校验，逐页成对查看D预览与F PowerPoint PNG并绑定两者哈希 | 以PowerPoint为准修正；不同字体栅格不要求像素相等，科学含义不能改变 |
| 最后一页时间不足 | 结论60秒review线、整稿速度/总量/停顿计划；人工审读口播内容 | 按内容分配，不重复开场凑时长；真实试讲仍需人工 |

新阈值仍集中于 `config/editorial-quality-policy.json`：正文字符420、内容包围区域12%–82%、8页以上单类占比45%、实际文本框容差3pt均为工程筛查。D的几何/密度是review，F实际文本框明显溢出是error。原图内部文字、科学对应、视觉重点、合理留白、语言自然与现场可读性不能用自动得分认证。自动修复至多原有两轮，仅安全字号等版式；其余由Codex修订有证据支持的C或有测试的编译器，并重新渲染。

已复核的边界案例：PowerPoint右对齐文字的COM BoundWidth可能包含字形留边。超框候选须再比对同次导出PDF的实际字形区域；字形正常不能仅按COM宽度判裁切，无法匹配则保留review。HTML样式属性整体转义，并检查浏览器实际计算字号与颜色，避免属性被字体名引号截断、白底文字继承白色而“对象存在但看不见”。这些规则均保留实际失败及修复证据。

D写`editorial-quality.json`；F在实际PowerPoint导出后写新的`editorial-quality.json`，绑定PPTX/PDF/规格哈希。F视觉审阅填写`editorialQualitySha256`及四个`editorialChecks`：`percentage-layout`、`figure-legibility`、`concise-sources`、`delivery-timing`。

review级提示在`editorialDispositions`逐项填写code、slideId、`status: accepted-after-actual-review`及rationale；error级必须修复并重新导出。每张实际PNG均要查看，不能批量预批准。原图字体不可读、测量不覆盖或现场投影不确定时明确保留限制。语义证据、数值和原图哈希门禁继续独立执行；这些排版检查不验证统计或经济模型。

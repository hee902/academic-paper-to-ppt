# 科学审读与图表规范

以已安装 scientific-critical-thinking、scientific-slides 和 scientific-visualization 的本地指南为依据；这些是过程指导，不是科学正确性认证。正式调用外部评价工具或引用新文献时另核验原始来源，不能照抄 Skill 的示例事实或未验证引用。

## 全文与主张

按[研究类型规范](research-routing.md)识别实际设计和推断范围，允许混合方法。定性/理论没有样本统计或回归模型可以明确not-reported，不为填表捏造数字。SEM路径不是因果证明，空间图核对投影/尺度，Meta保留异质性和偏倚，实验区分实验单位与重复。分类检查有来源/理由及当前B审核，不能复制案例批准。

1. 完整阅读所有页，记录原始题名、研究问题、实验/抽样单位、比较对象、结局与时间点。
2. 从原文定位方法、模型假设、样本来源、纳排标准、分析集、主要与次要结局及补充材料。缺失信息保持缺失。
3. 提取证据后再判断；区分描述差异、统计推断、预测、机制解释与因果结论。
4. 审查选择、测量、缺失数据、混杂、重复测量/伪重复、多重比较和模型假设；不同领域使用对应标准，不给整篇文章随意打质量分。
5. 对每个关键批评写来源位置、观察、影响、剩余不确定性。合理局限不能被包装成“研究无价值”。
6. 结论标题不得超过证据，作者推测与报告者判断明确标记。关键数字与讲稿中的数字都进入证据索引。

## 数值与图像核验

量的语义包括组别、分母、时点、单位及角色。百分数、百分点、比例、标准化效应与比值不能互换；CI/可信区间/预测区间/SE/报告范围不同。新原生区间摘要从B明确端点生成，逐项单位一致，水平单独为%，不乘系数补算、不强制比值零轴、不把范围改称CI。作者矛盾并列标注，不擅自修复。公式保留定义、条件与原件，不套用旧论文公式。

- 保留组别、n 的含义、分母、单位、时间点、效应量、比较方向、误差类型和统计检验。p 值不等于效应大小，非显著不等于等效。
- PDF 页码为可复查的主要锚点；章节、图表号、印刷页码作为 location 补充。文本锚点不可靠时使用原始裁图和实际视觉核验。
- 双栏表格、跨页表、合并单元格、科学记数法、负号、上/下标、希腊字母、公式等逐项回原图。MinerU basic 曾出现列错配，严禁直接将其表格当作已验证数据。
- 机器仅检查数值在引文中存在，不知道其是否属于正确组别或单位；审阅必须覆盖语义对应关系。哈希绑定只防止审阅过期，不证明判断本身正确。

## 科学可视化

### 离散量定义与公开数据复核

出现“均值±数值”先核对其统计对象、单位、分母、比较方向及原文定义。SD、SE、CI不能按幅度互相推断；正文未命名时保留“作者报告，类型未明确”，不默认95%CI。新增原生摘要显式使用B的`statisticalDefinitions`，旧运行不追填。

允许两种已验证依据：原文实际命名SD/SE（含s.d./s.e.），或只读公开数据后用独立脚本核对每行差值、行数、均值及样本SD（ddof=1），按原报告精度复现。保存公开URL、ZIP成员、文件SHA、列语义与审核理由；同舍入结果还需人工确认统计对象相同。不能执行未审查作者代码；不能把描述性复算称为完整模型复现。来源不支持则保持未定义或阻断该摘要。

复算说明与作者原报告分开：正向变化均值不授权翻转原配对t、效应量或CI的符号。记录相减顺序、原文与代码采用的比较对象、舍入差异及仍未解决的矛盾；不能替作者修复。SD刻画样本/空间点离散，不是均值不确定性；关联/情景预测也不是已证实因果。

### 面板与分组的科学对应

多图逐项记录面板号、状态或差值、情景条件、比较基准、单位、色标端点。量纲或范围不同的地图不能按相同颜色直接定量比较；单独情景不默认可相加或独立因果分解。相同字母用于不同分组时，在页面提示和Notes中区分所属体系。

箱线图按原图注核对箱、须、中心线和均值点；显著性横括号须对应正确组对，必要时回原统计表，不从像素推P值。未显著不等于等价。系数图逐项核对变量、标准化/原单位、零线、区间类型与水平、跨零及颜色含义；保留不显著项，不提高推断强度。

- 选择能回答本页问题的图形。坐标轴、刻度、单位、图例、分母与误差定义不得为了美观删除。
- 定量比较避免 3D、透视、面积编码误导；柱状图默认零基线。不能从光栅像素猜测出更精确数据。
- 目前主控原生 chart 只验收单系列简单柱图；误差线、多系列、复杂关系图保持原始图像。确定性 Matplotlib/Seaborn 适配器可用于有真实数据的新图，但接入新图须增加来源、构建及验证测试，不能绕过当前契约。
- 确定性图形采用已验证本地 Agg 后端；上游 presentation 小画布裁切失败仍保留。palette audit 仅提供配色建议，不能视为整张图的无障碍认证。
- 图片只裁去无关外边距，不移除图例或改变比例。若原图本身低清，报告限制或请求更清晰原始附件，不用生成式补图制造数据。

## 审阅边界

Codex 可以执行并记录实质审读，但不能声称另一个独立专家已审核。复杂结论无法确定则阻断相应主张，保留原始来源与原因。对专业科学结论的最终使用仍保留专家复核空间。不得自动调用付费图像/API、远程文档解析或上传论文。
